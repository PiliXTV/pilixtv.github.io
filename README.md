# PiliX TV

Filipino streaming hub — launch iWant, Netflix, Disney+, Prime Video, Viu, YouTube, and HBO from one place, with your PiliX badge at the center.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

PiliX TV never collects streaming passwords. Sign-in happens on each service’s official site; the hub keeps navigation inside the PiliX TV shell.
